# ANNIVO Web Platform

A cross-platform responsive web application for **ANNIVO Zero-Commission Food & Loyalty Club**, replicating all the mobile app features with high-craft Material 3 design and zero-commission guarantees.

## 🚀 Key Features

1. **Explore & Restaurant Browser**:
   - Filter by All, Offers, Top Rated, Favorites, and Pure Veg.
   - Live search across menus, cuisines, and dish categories.
   - Comprehensive menu cards with Veg/Non-Veg indicators, price details, and quantity counters.

2. **Smart Cart & Zero-Commission Bill Breakdown**:
   - Live subtotal, customizable rider tipping (₹0, ₹10, ₹20, ₹30, ₹50), and 5% packaging/GST.
   - Promo coupon discounts (`ANNIVO50`, `FREESHIP`, or redeemed loyalty vouchers).
   - Instant loyalty points calculation based on membership tier.

3. **Simulated 256-bit Razorpay Checkout**:
   - Interactive payment gateway with UPI / QR (GPay, PhonePe, Paytm), Debit/Credit Cards, NetBanking, and Cash on Delivery.
   - Instant order confirmation and confetti celebration.

4. **Live Order GPS Tracking Canvas**:
   - HTML5 dynamic delivery route simulation showing real-time rider progression on curved road bezier paths from partner kitchen to customer doorstep.
   - 4-step status progression timeline (*Placed* ➔ *Preparing* ➔ *On The Way* ➔ *Delivered*).

5. **ANNIVO Loyalty Club & Gamified Rewards**:
   - Tier progression (*Silver* ➔ *Gold* ➔ *Platinum*) with 1x to 2x point multipliers.
   - Total commission saved counter vs traditional aggregator markups.
   - **Daily Lucky Prize Wheel**: Canvas-rendered interactive spinning wheel with physical easing and instant point crediting.
   - **Scratch & Win**: Interactive silver-foil canvas scratch card with cursor/touch scratching and confetti prize reveal.
   - **Voucher Store**: Point redemption for flat ₹50 and ₹100 food vouchers.

6. **24/7 AI Support & Operational Ticketing**:
   - Instant AI chat assistant for queries regarding order tracking, loyalty mechanics, and refund policies.
   - Support ticket creation with real-time status tracking.

7. **Secure OTP Authentication & Heads-up SMS Slide-down Notification**:
   - Phone verification with simulated auto-fill slide-down notification banner and 60-second resend countdown timer (demo code: `123456`).

## 🛠️ Tech Stack
- **HTML5 & Modern Semantic Web Components**
- **Vanilla CSS3** with CSS Variables, Flexbox/Grid layouts, Glassmorphism, and responsive breakpoints
- **Vanilla JavaScript (ES6+)** with reactive state engine, HTML5 Canvas 2D graphics rendering, and Canvas Confetti
